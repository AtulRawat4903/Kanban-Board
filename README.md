# Kanban Board

A simple Kanban board built with **HTML, CSS, and JavaScript** to practice JavaScript concepts and DOM manipulation.

## Features

* Add new tasks
* Edit tasks
* Delete tasks
* Drag and drop tasks between columns
* Task count for each column
* Save tasks using LocalStorage
* Basic input validation

## Technologies

* HTML
* CSS
* JavaScript
* LocalStorage
* Drag and Drop API

## What I Practiced

* DOM manipulation
* Event listeners
* Drag and drop
* LocalStorage
* JSON
* Array methods
* Dynamic element creation
* Form/input validation
* Basic CRUD operations
